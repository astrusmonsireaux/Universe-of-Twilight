Game Features Test

Testing the enhanced Veauxalia game with new abilities and crafting system.

Instructions

  • Movement: WASD keys
  • Jump: Spacebar
  • Run: Shift
  • Telepathy: T key (when unlocked)
  • Time Perception: Y key (when unlocked)
  • Crafting: C key
  • Map: M key
  • Inventory: I key

New Features

  • Enhanced Player Abilities: Telepathy and Time Perception with cooldowns
  • Advanced Crafting System: Categorized recipes with descriptions
  • Special Items: Crystals that unlock abilities
  • Improved HUD: Ability indicators with cooldown visualization
  • Time Scale System: Time perception slows down game time
  • Enhanced Item System: More items with proper stacking and effects
